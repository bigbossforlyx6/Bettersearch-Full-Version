## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Enhanced Search Results** — Provides additional data and options for each search result, improving your overall search experience.
- **Site Thumbnails** — Displays a thumbnail image next to each result, giving you a visual preview.
- **Open in New Tab** — Easily open search results in a new tab for convenience.
- **Alexa Statistics** — Access statistical information about the website right from the search results.
- **Wayback Machine Links** — Direct access to the web history record for any site via the Wayback Machine.

### Advanced Features:
- **Magnifying Glass Function** — Preview details of a result before clicking through.
- **Social Network Information** — Shows relevant data about the results from social networks.
